# AutoCoin ERC-20-Style Chaincode

Fabric-native token chaincode used by the CarTrade case study. It is not an Ethereum contract.

## Transactions

- `Initialize`
- `Mint`
- `BalanceOf`
- `Transfer`
- `Approve`
- `Allowance`
- `TransferFrom`
- `Burn`
- `TotalSupply`

Org1 initializes and mints. Token balances are represented by organization MSP IDs for this simplified assignment.
